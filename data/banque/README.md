# Banque de questions

Vide pour l'instant : la banque sera écrite une fois les quatre agents construits
(décision du 15 octobre). Chaque question y référencera une donnée « demandée »
du classeur par son code (ex. `ACQ-01.02`). Voir `src/lib/donnees/schemas.ts`
(`question`) pour le contrat minimal. Rien n'est inventé en attendant : le script
`npm run donnees:controle` liste les données demandées qui n'ont pas encore de
question.
